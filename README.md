
# MySQL Student Database – SQL Practice

This project includes SQL queries developed using MySQL to practice and gain a better understanding of basic SQL concepts. It is based on a college database (`college_db`) that stores student and enrollment details.

## Topics Covered

- SELECT statements
- WHERE clause
- AND, OR operators
- NOT IN operator
- BETWEEN operator
- LIKE operator and pattern matching
- NULL and IS NULL conditions
- ORDER BY (ASC and DESC)
- LIMIT clause
- Filtering and organizing student records
- Identifying top-performing and youngest students

## Objective

To strengthen SQL querying skills by working on practical exercises using student and enrollment data.

## Tools Used

- MySQL
- MySQL Workbench
